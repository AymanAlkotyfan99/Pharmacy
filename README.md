# بدايةُ أثر — دعوة تخرّج الصيدلة

افتح `index.html` مباشرة في متصفح حديث. لا تحتاج الدعوة إلى خادم، أو تثبيت، أو اتصال بالإنترنت. روابط الخرائط فقط تحتاج إلى الإنترنت.

## تخصيص الدعوة

- عدّل الاسم والجامعة والتاريخ والقاعة ورابط الخريطة في كائن `graduationData` أعلى `js/script.js`.
- التاريخ الذي لا يحتوي على منطقة زمنية يُقرأ بتوقيت دمشق `UTC+03:00`. يمكنك كتابة إزاحة زمنية صريحة في نهاية التاريخ عند الحاجة.
- أضف صورتك باسم `assets/graduate.jpg`. عند غيابها يظهر تصميم فني يحمل الاسم.
- استبدل الصور التجريبية `assets/gallery-1.jpg` حتى `assets/gallery-6.jpg` بصورك. الصور المرفقة عينات تحريرية، وليست صور الخريج أو جامعته الفعلية.
- الصور المفقودة لها تصاميم بديلة خاصة بها، وتعمل هذه البدائل في المعرض المكبّر أيضًا.
- رابط الخريطة الحالي تجريبي. ضع رابط الموقع الدقيق في `mapUrl` قبل إرسال الدعوة.

## التفاعل وإمكانية الوصول

انقر الكبسولة أو اضغط Enter عند التركيز عليها لبدء المقدّمة التي تستغرق نحو 4.2 ثانية. زر تجاوز المقدّمة متاح دائمًا. افتح الصور ثم تنقّل بالأزرار، أو السحب، أو سهمي لوحة المفاتيح؛ Escape يغلق المعرض. نقاط الجزيء تستجيب للفأرة واللمس ولوحة المفاتيح.

تُحترم إعدادات تقليل الحركة، ويمكن إيقافها من أسفل الدعوة. تتوقف حلقة الرسم عند إخفاء الصفحة. إذا كان JavaScript معطّلًا، يبقى محتوى الدعوة قابلًا للقراءة.

## الملفات

`index.html` — المحتوى العربي والبنية الدلالية.

`css/style.css` — التصميم، الكبسولة، الإضاءة، الرسوم، والتخطيطات المتجاوبة.

`js/script.js` — البيانات والتفاعلات، دون مكتبات أو وحدات تستدعي خادمًا.

`assets/` — صور قابلة للاستبدال وخطوط عربية محلية. المصادر والتراخيص موثّقة في `assets/README.txt` وملفّي OFL.

Built exclusively with HTML5, CSS3, and vanilla JavaScript. No framework, external UI library, build step, or runtime CDN dependency.
